# QuickEats Monorepo

## Servicios
- **auth-service**: NestJS, Prisma, JWT, Supabase
- **restaurant-service**: NestJS, productos y restaurantes
- **order-service**: Gestión de órdenes
- **gateway**: API Gateway
- **frontend**: Next.js 

## Trabajar con:
- Abre carpeta en VS Code: `File → Open Folder`
- Usa @-mentions para archivos específicos: `@archivo.ts` 
- Cada sesión = un servicio (no todo el monorepo junto)

## Reglas
- NO ejecutar npm run build
- NO ejecutar npm install
- NO ejecutar npx tsc ni type-checks
- NO ejecutar comandos de terminal salvo que se pida explícitamente
- Solo leer y modificar archivos fuente
